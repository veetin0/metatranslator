# Rules

Source: challenge/brief/CHALLENGE.md (Meta × Junction 2026). No separate rulebook supplied; Junction general rules not in material (ask organisers).

## Hard rules (R)
- R1 — Must use AI glasses from Meta. "Build the best everyday use case using AI glasses from Meta"
- R2 — Must show a first-person field of view benefit, not just phone mirroring. "showing how a first-person field of view enables new or better interactions in everyday scenarios" / "beyond simply mirroring a phone screen"
- R3 — Appropriate consent and safe data practices within the demo's scope. "with appropriate consent and safe data practices within the demo's scope"
- R4 — Deadline 2026-11-15T10:00+02:00 (hackforge.yaml; organiser deadline not in material — confirm).

## Deliverables (D)
- D1 — Functional prototype. "deliver a functional prototype and deck"
- D2 — Deck. "deliver a functional prototype and deck"
- D3 — Prototype handles permissions, errors, performance trade-offs, connectivity, and device state changes. "backed by a functional prototype that handles permissions, errors, performance trade-offs, connectivity, and device state changes"
- D4 — Clear problem and intended audience articulated. "Best entries will clearly articulate the problem and intended audience"
- D5 — Plausible path to adoption or a pilot. "a focused, plausible path to adoption or a pilot"

## Judging criteria (J) — equal weights
- J1 — Creativity and use case (25%)
- J2 — Technical execution (25%)
- J3 — Real-world value and feasibility (25%)
- J4 — User experience: input, accessibility and trust (25%)

## Implicit expectations
- I1 — Inclusive for people with all abilities: the deaf signer's experience matters, not just the hearing wearer's (two-way: reply path for the hearing person, e.g. their speech → captions the signer can see).
- I2 — Display and audio-first count equally; web apps and DAT mobile integration count equally — pick what works on the shared devices.
- I3 — Original, relevant use case with a clear wearable benefit (hands-free, eye contact kept).
- I4 — Live demo on real glasses will be expected by Meta judges; mentors are Web Apps and DAT engineers, so using their platforms properly scores J2.
- I5 — Honesty about recognition limits (bounded vocabulary, confidence shown) supports J4 trust.
