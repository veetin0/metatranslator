# Directives

Team instructions. They override HackForge defaults, never an official rule.

1. Build "Signer": AI tool translating sign language into text and speech for hearing people (source: challenge/brief/CHALLENGE.md, team note).
2. A deaf person signs in front of a person wearing Meta Ray-Ban Display glasses; the system captures movement via camera, recognises signs and expressions, converts to text, shows text on the glasses, and plays it via TTS (source: challenge/brief/CHALLENGE.md, team note).
3. Find the best tools, how to build it, and how it can be a real app on the glasses (source: challenge/brief/CHALLENGE.md, team note).
4. We have Meta glasses to use (source: challenge/brief/CHALLENGE.md, team note).
5. Modalities: suggest — propose non-code deliverables only where they raise a criterion (source: hackforge.yaml `modalities`).
6. allow / forbid / stack_preferences: none set (source: hackforge.yaml).
7. Follow Meta's developer docs for how the app gets onto the glasses (Web App on the display); use Meta's display simulators so development doesn't need glasses and the web app transfers easily to the device (source: lead, [run] 2026-11-13).
8. English only: sign-language datasets and output in English (ASL → English); FinSL dropped (source: lead, [run] 2026-11-13).
9. Use Meta's DAT iOS sample BirdSpotter as the example of a glasses app (source: lead, [run] 2026-11-13).
10. Build on iOS: paid Apple developer team + iPhone on iOS 17.2+. "English sign language" = ASL. No Kaggle account, so no Kaggle `asl-signs` (source: lead, 2026-11-13).
11. Meta's references for the build: Display Simulator, DAT getting-started docs, Web Apps docs, and the repos meta-wearables-webapp, meta-wearables-dat-ios, meta-wearables-dat-android. Pass them to every agent and crew member. Meta's plugins and docs MCP may be installed (source: lead, 2026-11-13).
12. The Ray-Ban Display is available in 2-hour reservations: plan hardware work into booked slots and develop with Mock Device Kit + simulator between them. Pitch is 2 minutes, not in focus yet (source: lead, 2026-11-13).
